# OneToolBox — Real Tool UI Fix

The generated pages previously reused a generic hidden file input for almost every category.
That has been corrected.

- Calculator: numeric/form inputs, no file chooser.
- Utility: text/options, no file chooser.
- Developer: code/data text inputs, no file chooser.
- AI: prompt/text inputs, no file chooser (real cloud AI still requires an API).
- Document: text/document inputs.
- Audio/Video: file chooser because those tools operate on media files.
- Media converters: file chooser.
- Numeric converters: value/unit inputs.

Image Tools and PDF Tools from the supplied project were preserved.
