FAQ

Can I edit text directly in the screenshot?

Yes. OCR creates editable text overlays at the detected positions.

Will the original font be exactly detected?

Not always. A flat screenshot does not contain the font file, so the editor estimates the closest browser font while preserving the detected size and color.

Can I add my own text and images?

Yes. Use the Text and Image buttons in the left panel.

Does the original background stay?

The screenshot remains the base image. When a recognized text item is edited, the editor uses a local background patch behind the replacement text where practical.
