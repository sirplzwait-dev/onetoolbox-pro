How to Resize an Image?

Resize your image in a few simple steps without uploading it to a server.

1

Upload Your Image

Click Choose Image and select the image you want to resize.

2

Set Dimensions

Choose PX, CM or INCH, then enter your required width and height.

3

Keep Proportions

Keep Maintain Aspect Ratio enabled to preserve the original image proportions.

4

Resize & Download

Click Resize Image, check the result and download the resized image.

For highly sensitive files, always review your browser and device environment before processing.

Need Help?

Frequently Asked Questions

Quick answers about the OneToolBox Image Resizer.

Is the Image Resizer free?

Yes. The OneToolBox Image Resizer is provided as a free online utility.

Which units can I use?

You can resize using PX, CM or INCH. DPI is used for CM and INCH conversion.

What does Maintain Aspect Ratio do?

When enabled, changing width automatically calculates the height, or changing height calculates the width, according to the original image ratio.

What DPI should I use?

DPI depends on your intended use. The tool starts with 300 DPI, and you can change it when working with CM or INCH measurements.

Will resizing stretch my image?

If Maintain Aspect Ratio is enabled, the tool preserves the original width-to-height proportion. Turn it off only when you intentionally need a custom width and height.

Can I see the result before downloading?

Yes. After resizing, the result preview, new dimensions and new file size are shown before you download the image.

Is my image uploaded to OneToolBox?

The current resize code processes the selected image locally in the browser with JavaScript and Canvas; it does not contain an upload request for the selected image to a OneToolBox server.

Which image formats are supported?

The file picker accepts browser-supported image files. Actual format support can depend on the browser's image decoding and Canvas capabilities.
