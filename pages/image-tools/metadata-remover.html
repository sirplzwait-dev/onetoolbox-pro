Frequently Asked Questions

What is image metadata?

Metadata is information stored with an image, such as camera details, timestamps, orientation and sometimes location information.

Does this tool upload my image?

No. The image is decoded and redrawn in your browser. No upload request is made by this tool.

Will the original file be changed?

No. The original file remains untouched. You download a newly generated clean copy.

Does this remove every possible type of metadata?

Redrawing the image into a fresh canvas removes metadata that is not intentionally re-created in the exported file. Metadata behavior can vary by format and browser, so this tool should not be treated as a forensic guarantee of zero metadata.

Which formats are supported?

JPG, PNG and WebP input are supported. You can export the cleaned copy as PNG, JPG or WebP.
