Privacy & File Handling

This PDF compressor performs its main processing in the browser using PDF.js, canvas and browser APIs. It does not upload the selected PDF to a OneToolBox server.

Frequently Asked Questions

Is the PDF compressor free?

Yes. It is designed as a free browser-based utility.

Can I select a target size?

Yes. You can choose 10 KB, 20 KB, 50 KB, 100 KB or Custom.

Will every PDF reach the exact target size?

Not always. The output depends on page content, image complexity and the browser PDF renderer. The tool attempts to get close to the selected target.

Will text quality remain exactly the same?

Pages are optimized as rendered images, so very small target sizes can reduce visual quality and selectable text may no longer remain selectable.

Is my PDF uploaded to a server?

No external upload API is used by this page. Processing happens in the browser.
