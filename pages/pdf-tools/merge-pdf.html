FAQ

Frequently Asked Questions

Can I merge multiple PDF files?

Yes. Select multiple PDF files and the tool will combine them into one PDF.

Will my original PDFs be changed?

No. The original files are not modified. A new merged PDF is created.

Can I merge large PDFs?

The practical limit depends on your browser memory and the size and number of PDF files.

Does the page order matter?

Yes. The files are merged in the order displayed in the PDF Order box.
