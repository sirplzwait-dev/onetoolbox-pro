FAQ

Can it read scanned PDFs?

Yes. Each PDF page is rendered as an image and processed with OCR.

Does Hindi OCR work?

Yes, select Hindi or English + Hindi. The first language load requires an internet connection.

Are my files uploaded?

No PDF upload to a server is required by this tool.
