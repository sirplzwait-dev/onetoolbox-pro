Frequently Asked Questions

What is a color picker?

A color picker lets you select a color and obtain its exact digital color values.

What is HEX color?

HEX is a six-digit hexadecimal color representation commonly used in HTML and CSS.

What is RGB?

RGB represents a color using Red, Green and Blue values from 0 to 255.

What is HSL?

HSL represents color using Hue, Saturation and Lightness.

Can I copy the color values?

Yes. Each HEX, RGB, HSL and CSS value has its own copy button.
