❓ Frequently Asked Questions

How does background removal work?

The tool uses an in-browser image segmentation model to separate the foreground subject from the background.

Does my photo get uploaded to a server?

The background-removal processing is performed in the browser. The model assets are downloaded when required.

Can I use a custom background image?

Yes. Upload JPG, PNG or WebP and use it as the new background.

Can I make the background transparent?

Yes. Select Transparent and export the result as PNG.

Why is the first processing slow?

The background-removal model and WASM assets need to be downloaded and cached the first time. Later processing can be faster.

Which formats are supported?

JPG, JPEG, PNG and WebP are supported as input formats.
