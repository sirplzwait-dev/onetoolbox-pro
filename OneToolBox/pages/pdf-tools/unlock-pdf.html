FAQ

Frequently Asked Questions

Can this tool remove a PDF password?

Yes, if you provide the correct password for the PDF.

Can it crack an unknown password?

No. This tool requires the existing password. It does not brute-force or bypass an unknown password.

Will my original PDF change?

No. A new unlocked PDF is created and the original file is left unchanged.

Is my PDF uploaded to a server?

No. The PDF is processed in your browser using QPDF WebAssembly.
